# Production fonts

Outfit (body) and Syne (headings) are self-hosted, unmodified variable fonts.

- Outfit: https://github.com/google/fonts/tree/main/ofl/outfit — outfit-OFL.txt
- Syne: https://github.com/google/fonts/tree/main/ofl/syne — syne-OFL.txt

Both use the SIL Open Font License. No third-party font requests are made.
